## CS50 C Programs

Located in `CS50/c/`, this folder contains several beginner-friendly C programs inspired by the CS50 course. Each program demonstrates fundamental programming concepts:

- **agree.c**: Simple yes/no input program. Asks the user if they agree and prints a response based on their answer.
- **cat.c**: Demonstrates loops and functions by printing "Meow" multiple times using a function.
- **condition.c**: Takes three integers as input and prints which one is the greatest, demonstrating conditional logic.
- **hello.c**: Greets the user by name and welcomes them to CS50, showing basic input/output.

To compile and run any C program:

```sh
# Example for hello.c
cd CS50/c
gcc hello.c -o hello
./hello
```
